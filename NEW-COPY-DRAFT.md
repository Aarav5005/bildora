### NEW — The platform: agent architecture (#platform)
Heading: "ONE SYSTEM. SPECIALIZED AGENTS."
Subhead: "This is the architecture we're building toward — starting with one
workflow, proven with real manufacturers. Initially these run as coordinated
modules under one orchestrator; they earn the name 'agent' as each workflow
proves itself."
- Input channels line: "WhatsApp · Voice · Email · PDF · Your existing software"
- The seven agents (name + one-line responsibility):
  1. Orchestrator / Operations Manager — understands the request, assigns work,
     tracks status, requests approvals.
  2. Order Agent — extracts orders from any channel, drafts structured records.
  3. Inventory Agent — checks stock, material needs, and shortages.
  4. Production Agent — tracks jobs, dependencies, and delays.
  5. Procurement Agent — prepares purchase requests, compares approved suppliers.
  6. Accounts Agent — extracts invoices, checks them against order records.
  7. Owner Insights Agent — summarizes pending orders, risks, and exceptions.
- Shared controls strip: "Company-specific data permissions · Audit logs ·
  Human approvals for consequential actions · Error handling — your data never
  leaks into another business."
